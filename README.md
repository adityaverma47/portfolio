# Aditya's Portfolio

A modern, interactive portfolio website built from scratch to showcase my work as a creative developer.

## Tech Stack

This project is built with a focus on performance, aesthetics, and modern web standards:

- **React**: Component-based UI methodology.
- **TypeScript**: Type safety and developer experience.
- **Vite**: Fast build tool and dev server.
- **Tailwind CSS**: Utility-first styling for rapid development.
- **GSAP**: Professional-grade animations and ScrollTrigger effects.
- **Three.js / Spline**: Immersive 3D elements.
- **Shadcn UI**: Accessible and customizable component primitives.

## Features

- **3D Hero Section**: Interactive 3D scene using Spline.
- **Project Showcase**: Detailed project pages with tech stack and features.
- **Education Timeline**: Visual history of academic achievements.
- **Smooth Animations**: GSAP-powered transitions and scroll effects.
- **Responsive Design**: Fully optimized for all device sizes.

## Getting Started

To run this project locally:

1.  Clone the repository:
    ```bash
    git clone https://github.com/bugSlayer555/portfolio.git
    ```
2.  Install dependencies:
    ```bash
    npm install
    ```
3.  Start the development server:
    ```bash
    npm run dev
    ```
